# AutoSwitcher

Автоматический переключатель раскладки клавиатуры для macOS в духе Punto Switcher / Caramba Switcher. Открытый код, работает локально, ничего не отправляет в сеть.

## Как работает

Приложение слушает клавиатуру и анализирует набираемое слово **по префиксной модели**:

1. Вы печатаете, например, `ghbd`. Уже на 4-м символе становится ясно: в английском языке не существует слова, начинающегося на `ghbd`, а вот `прив` — это живое начало русских слов. Срабатывает триггер.
2. AutoSwitcher переключает раскладку на русскую, стирает `ghbd` и вбивает `прив`.
3. Вы продолжаете печатать `ет` — уже в правильной раскладке. Итог: `привет`.

Симметрично работает и обратный случай: `руддщ` → `hello`, раскладка переключается на английскую.

Ложные срабатывания отсекаются тремя проверками:
- набранный вариант должен быть **мёртвым префиксом** в текущем языке (никакое слово так не начинается);
- проекция на другой язык должна быть **живым префиксом** реального слова;
- набранное слово не должно быть реальным словом текущего языка (`github`, `hell` не трогаются).

Исправления на границе слова (пробел, знак препинания) работают и для коротких слов от 3 букв. После Enter/цифр текст не исправляется — уже отправленное исправлять опасно.

## Словари

Частотные словари из [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords) (корпус OpenSubtitles 2018): ~48 тыс. русских и ~47 тыс. английских слов. При запуске фильтруются и превращаются в префиксные деревья (tries).

## Что отключено по умолчанию

- **Поля пароля** (Secure Event Input) — там набранное не перехватывается и не исправляется.
- **Терминалы**: Terminal, iTerm2, Warp, kitty, Alacritty, Ghostty — список в `Sources/AutoSwitcherCore/AppFilter.swift`.
- Приложения, где активна раскладка, отличная от RU/EN пары (немецкая, французская и т.д.).

## Сборка

Нужны только Command Line Tools (`xcode-select --install`), полный Xcode не требуется.

```bash
# Тесты логики (37 проверок, включая реальные словари)
swift run TestsRunner

# Сборка приложения
./scripts/make-app.sh
open AutoSwitcher.app
```

## Первый запуск

1. После `open AutoSwitcher.app` в меню-баре появится значок клавиатуры.
2. Клик по значку → «⚠️ Нужны разрешения» → выдайте приложению:
   - **Accessibility** (Универсальный доступ) — чтобы стирать и вбивать текст;
   - **Input Monitoring** (Мониторинг ввода) — чтобы слушать клавиатуру.
3. Нажмите «Перезапустить слежение» (⌘R) — статус сменится на «✓ Готов к работе».
4. **Настройки…** (⌘,) открывают окно: вкл/выкл, звук, пороги длины слов, статус, версия.

> ⚠️ При каждой пересборке ad-hoc подпись меняется, и macOS может заново запросить разрешения. Для разработки удобнее выдавать разрешения своему терминалу и запускать `swift run AutoSwitcher`.

## Настройки-константы (Sources/AutoSwitcherCore/LayoutDetector.swift)

| Константа | Значение | Смысл |
|---|---|---|
| `minLiveLength` | 4 | с какой длины слова включается исправление на лету |
| `minBoundaryLength` | 3 | минимальная длина слова для исправления на пробеле |

## Ограничения текущей версии (v0.1)

- Работает только с парой русская (ЙЦУКЕН) + английская (ABC/US) раскладки.
- Переввод через unicode-payload событий: в редких приложениях (некоторые эмуляторы терминалов) может вставляться иначе.
- Нет автокоррекции опечаток внутри слов и статистической модели «на лету посимвольно» — срабатывание происходит по префиксам слов из словаря.
- Нет конфиг-файла: исключения и константы правятся в исходниках.

## Структура

```
Sources/AutoSwitcherCore/     — чистая логика (без UI): маппинг, trie, детектор, словари
Sources/AutoSwitcher/         — системный слой: event tap, TIS, переввод, меню-бар
Sources/TestsRunner/          — тесты (XCTest недоступен без Xcode, поэтому свой раннер)
scripts/make-app.sh           — сборка .app
```
